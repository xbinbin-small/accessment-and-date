# UI/UX 设计规范 (Desktop / Admin Dashboard)

## 1. 布局原则 (Admin Layout)
- **整体结构**: 经典的“侧边栏 + 顶部导航 + 内容区”布局。
  - **Left Sidebar**: 固定导航（患者列表、风险预警、系统设置）。
  - **Main Content**: 数据展示区。
  - **Right Panel (可选)**: AI 助手常驻侧边栏或悬浮窗。
- **分屏交互 (Split Pane)**: 
  - 在详情页中，采用 **左右分屏** 设计。
  - **左侧 (60%)**: 复杂的 `Recharts` 组合图表（如血压与血糖的叠加趋势）和详细历史数据表格。
  - **右侧 (40%)**: `DeepSeek` AI 对话窗口。医生可以一边看左边的图，一边在右边问 AI，无需跳转页面。

## 2. 关键组件规范
- **数据表格 (Data Table)**:
  - 替代移动端的“卡片列表”。
  - 必须支持：**分页、列排序、按风险等级筛选、搜索**。
  - 使用 Shadcn UI 的 `Table` 组件配合 `TanStack Table` 逻辑。
- **图表 (Charts)**:
  - 利用大屏优势，展示更复杂的图表，如包含“正常范围阴影区”的折线图。
  - 鼠标 Hover 时需显示详细 Tooltip。

## 3. 视觉风格
- **密度**: High Density（高密度）。相比移动端，桌面端应减少留白，在一屏内展示更多数据。
- **字体**: 正文 14px，标题 16px-24px。
- **主题**: 干净的医疗蓝/白配色，高危数据用醒目的红色高亮。

## 4. 交互反馈
- **快捷键**: 支持 `Enter` 发送消息，`Esc` 关闭弹窗。
- **Loading**: 局部加载（例如切换患者时，只有图表区域转圈，侧边栏不动）。
