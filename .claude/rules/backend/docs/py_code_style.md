# Python 代码风格指南

- **规范**: 遵循 PEP 8。
- **类型提示**: 所有函数必须包含 Type Hints (如 `def get_data(id: str) -> dict:`)。
- **文档**: 复杂逻辑函数需编写 Google Style Docstring。
- **异步**: 数据库 I/O 操作必须使用 `async/await`。
- **错误处理**: 使用 FastAPI 的 `HTTPException` 抛出错误，禁止直接崩溃。
- **依赖**: 使用 `poetry` 管理依赖，禁止直接 `pip install`。
- **日志**: 使用 `logging` 模块记录日志，禁止直接 `print`。
- **测试**: 所有新增功能必须编写单元测试。
- **代码格式**: 使用 `black` 和 `isort` 格式化代码。
- **代码质量**: 使用 `pylint` 和 `mypy` 检查代码质量。
- **代码复用**: 禁止复制粘贴代码，必须抽象成函数或类。
- **代码简洁**: 禁止过度设计，必须保持代码简洁。
- **代码可读性**: 变量名、函数名必须具有描述性。
- **代码一致性**: 代码风格必须保持一致。
- **代码安全**: 禁止直接拼接 SQL 语句，必须使用参数化查询。
